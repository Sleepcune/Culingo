# CuLingo v0.1 执行记录

目标：Chrome / Edge 个人自用扩展，英语阅读、简体中文释义、本地保存词汇及复习数据。

## 交付清单
- [x] 扩展骨架、权限、后台通信
- [x] 固定版本 ECDICT 离线词库及初始化
- [x] 不改变原文结构的高亮、悬浮查词、划词、发音
- [x] 可配置翻译服务、段落与全文双语、缓存与取消
- [x] 生词本、例句、状态、跨标签页通知
- [x] FSRS 闪卡复习、持久化与幂等评分
- [x] JSON/CSV/Anki 导入导出
- [x] 自动测试、生产构建及安装说明
- [x] 最终安装包生成及 Manifest、可选权限、词库许可证检查

测试工具：Vitest + fake-indexeddb，Playwright 持久化 Chromium 扩展环境。
PDF、视频字幕、云同步与商店发布不在本次范围。真实 API 和一周自用需用户环境验证。

## 实现和验收的区别

本次实现了七个阶段的首版功能。自动验收使用受控文章和模拟 Chat Completions 服务，不能代替真实网站兼容性、Edge 实机和一周日常使用。原计划中的这些人工验收保留为待办，具体测试记录见 `VERIFICATION.md`。
