# CuLingo

在英文网页中遇见、理解、积累和复习词汇。个人自用的 Chrome / Edge Manifest V3 扩展，中文界面，词汇数据保存在本机。

## 安装

1. 下载本项目交付的 `culingo-0.1.0-chrome.zip`，解压到一个固定文件夹。已有源代码构建结果时，可直接使用 `.output/chrome-mv3` 文件夹。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的扩展文件夹，不要选择项目根目录或 ZIP 文件。
5. 将 CuLingo 固定到工具栏。打开英文网页，点击插件中的“授权并启用此网站”，在浏览器原生对话框中确认。
6. 首次使用等待本地词典初始化完成。以后查词、高亮、生词本及闪卡可离线使用。

更新时先导出备份，将新版本覆盖到原安装文件夹，然后在扩展管理页点击“重新加载”。保持同一文件夹有助于保持扩展身份和本地数据。不要通过卸载来更新；卸载会移除本地学习数据。

## 阅读

- 绿色高亮表示超出所选词频档位的词；金色高亮表示你收藏的学习词。
- 悬停约 250 毫秒显示单词卡，查看音标、词义、词性，播放发音、复制、收藏或标记掌握。
- 收藏时保存页面标题、地址和当前例句。已掌握的词不再自动高亮，并暂停复习；恢复学习保留原复习进度。
- 划选单词、短语或句子后，点击出现的“查词 / 翻译”。短语可以收藏，最长 200 字符；更长文本只能翻译。
- 词频档位为 3000 / 5000 / 8000。它们是阅读提示强度，不是英语水平测评。
- 本地词典未收录的词可手动收藏并编辑释义；单词卡也提供“AI 释义”，需要先配置翻译服务，生成的“AI 中文释义：…”只有在点击收藏后才会写入生词本。单词卡的句子翻译与词典释义分开；翻译句子后再次收藏可保存其译文。
- 输入框、编辑器、代码块和隐藏区域不自动扫描；跨域 iframe、封闭 Shadow DOM、PDF 与浏览器内置页不支持自动高亮。

发音使用系统英语语音。缺少语音时安装系统英语语音包；语音是否完全离线取决于系统提供的语音。

## 配置翻译

从插件打开“阅读设置”，填写兼容 Chat Completions 的服务：

| 字段 | 示例 |
| --- | --- |
| API 根地址 | `https://服务域名/v1` |
| API Key | 你自己的服务密钥 |
| 模型名称 | 服务提供的准确模型标识 |

保存或测试时，浏览器会请求该服务域名的访问权限。根地址不要包含 `/chat/completions`，CuLingo 会自动拼接。远程服务必须使用 HTTPS；`localhost`、`127.0.0.1` 和 `::1` 可使用 HTTP，本地服务允许空密钥。首版支持非流式文本响应，不支持供应商专有接口。

单词卡中可“翻译当前句子”或“翻译本段”。工具栏弹窗中“切换当前页双语阅读”会按可见区域逐段翻译，滚动时继续处理。“恢复原文”取消等待任务并移除译文，保留原文。选中文本所在段落也可用 `Alt+T` 翻译，`Esc` 关闭查词卡。

同时最多两个请求，单次请求 25 秒超时。鉴权失败不重试；限流或服务器故障重试一次。译文缓存按服务、模型、原文、语言和提示词版本区分，容量上限 50 MB。已经发出的请求即使取消，也可能被服务方计费。

## 生词本和复习

管理页支持搜索、学习状态筛选、手动添加单词或短语、编辑释义、查看来源及批量操作。

“今日复习”显示到期卡片，再加入最多 20 个当天新词。先回忆，再显示答案，选择“忘记了 / 有点难 / 记得 / 很轻松”。调度使用 ts-fsrs，目标保持率 0.9，进度和复习历史保存在本地。没有回忆起来时选择“忘记了”。

## 备份与导入

- **JSON**：完整保存词汇、例句、复习卡、复习历史和阅读偏好，不含 API 配置、密钥或翻译缓存。
- **CSV**：词汇表格式，包含 `word,meaning,example,url`；导入还接受可选 `title`。支持带引号、逗号和换行的字段。
- **Anki TSV**：四列为词汇、释义、例句、来源。导入 Anki 时映射到对应字段；不导出 `.apkg` 或 Anki 调度状态。

导入前显示预览，确认后合并。已有词汇按修改时间选择较新内容，例句与日志去重；复习卡采用最近一次复习的状态。CSV 新词建立新卡，不覆盖现有调度。阅读偏好恢复后仍需要相应浏览器授权。JSON 导入不恢复 API 配置。

建议定期导出 JSON。数据不自动同步，不上传到 CuLingo 服务器；本项目没有服务器。

## 本地开发

需要 Node.js 22 或更新的受支持版本。依赖安装在项目内，不需要 Python。

```powershell
npm ci
npm run typecheck
npm test
npm run build
npm run zip
```

`npm run dev` 开启开发构建。`npm run browser:install` 将测试 Chromium 安装到项目 `.cache/playwright`，然后运行 `npm run test:e2e`。

词库已经生成并随扩展打包。重新生成时，把固定版本 ECDICT 的 `ecdict.csv` 和 `LICENSE` 放入 `data/source`，运行 `npm run dictionary`。`data/dictionary-extra.json` 保存少量低频补充词条；这些词可离线查询但不会因为词频为 0 自动高亮。来源版本见 `public/dictionary/manifest.json`，构建脚本见 `scripts/build-dictionary.mjs`。如果添加 Python 数据处理脚本，使用项目本地 uv `.venv`。

## 数据与权限

安装时不申请整站访问；默认仅在主动授权的站点启用。也可在设置中主动启用所有普通网站，并为个别站点关闭。

API 密钥保存在仅可信扩展页面和后台可访问的本机 Storage 区域，普通网页脚本不能读取。它不是加密保险箱。基础高亮、查词和复习不发送正文；翻译时只把要翻译的文本发送到你配置的服务。来源 URL 和例句属于本地词汇记录，会进入你主动导出的备份。

诊断只记录时间、代码和耗时，不记录密钥或正文。译文作为纯文本显示，不执行远程代码。

## 验证边界

自动验证覆盖数据库、词形、备份、FSRS、翻译重试／缓存／取消和隔离 Chromium 的阅读流程。无界面 Chromium 无法确认浏览器原生扩展权限对话框，因此端到端测试只在独立测试副本中预授予主机权限，同时检查正式安装包仍为可选权限。

Edge 实机、真实翻译供应商、复杂网站及连续一周日常使用需要在你的实际使用环境中继续验证；本次交付不宣称已完成这些长期验收。
