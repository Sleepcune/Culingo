# CuLingo for Zotero v0.1

Windows 64 位 Zotero **10.0.5** 的独立阅读学习插件。生词、例句、复习、设置和翻译缓存保存在 Zotero 配置目录；不会修改或同步浏览器版的数据。

## 安装与首次使用

1. 在 Zotero 中打开「工具 → 插件」。点击齿轮，选择「从文件安装插件」。
2. 选择 `dist/culingo-zotero-0.1.0.xpi`，确认安装并启用。若入口没有出现，重启 Zotero。
3. 等待离线词典初始化完成。首次使用显示分块进度；以后直接使用已有本地词库。
4. 打开有可提取文字的英文 PDF。默认进阶等级，生词呈黄色提示，已收藏的学习词呈蓝色提示。
5. 鼠标停留约 250 毫秒显示查词卡。也可划选文本，点击选区弹窗里的「CuLingo 查词 / 翻译」。
6. 在卡片中查看释义、编辑例句、收藏或标记掌握。已掌握的词停止提示和复习。
7. 点击阅读器工具栏「生词本」，或「工具 → CuLingo 学习中心」，管理词汇、复习及备份。

无需 API 即可高亮、离线查词、收藏和复习。发音依赖宿主可用的英语语音；无可用语音时会显示提示。

查词卡会在释义、按钮或译文加载后重新定位，保持在阅读器窗口内；可拖动卡片标题调整位置，窗口缩放时也会重新适配。

离线词库包含固定版本的 ECDICT 及少量补充词条；补充词条用于覆盖低频但有明确释义的阅读词，不会因为词频为 0 而自动高亮。查词卡遇到仍未收录的单词时，在已配置翻译服务的情况下可点击「AI 释义」；结果会以「AI 中文释义：…」格式显示，只有点击「收藏」才会保存到独立的 Zotero 生词本。

## 阅读与双语

- 在学习中心「设置」选择基础、进阶、高阶，对应约 3000、5000、8000 常用词。等级用于提示强度，不是英语水平测评。
- 查词卡可以分别编辑释义和例句。点击「翻译例句」后再收藏，会保存对应原文的译文；如果随后修改了原文，请重新翻译。
- 划选单词优先离线查询；短语、句子也可查询、手动填写释义或翻译后收藏。
- 配置翻译服务后，点击阅读器工具栏「CuLingo」打开右侧双语栏并开启整篇模式。原 PDF 保持原样。
- 侧栏「翻译当前页」只请求当前页文本；整篇模式按可见页处理，翻页后继续，不在开启时一次发送整篇论文。
- 侧栏每段的「定位原文」返回对应页面。「选区或段落翻译」支持粘贴一段文本，查词卡支持直接翻译选区或例句。
- 关闭整篇双语清除侧栏译文并取消任务；切换文档暂停旧文档的请求，返回后继续。已经发出的请求可能产生供应商计费。
- 页面临时覆盖层不创建 Zotero 原生批注，也不修改 PDF 文件。原有链接、选区、搜索及批注由 Zotero 处理。

## 翻译配置

在「学习中心 → 设置 → 翻译服务」单独填写三个字段，随后「保存并测试连接」。

| 字段 | 示例与含义 |
| --- | --- |
| 接口根地址 | `https://api.example.com/v1`，由插件追加 `/chat/completions` |
| 模型名称 | 供应商或本地模型提供的名称 |
| API 密钥 | 供应商密钥；本地回环服务可以留空 |

支持非流式 Chat Completions 文本响应。远程地址须使用 HTTPS；`localhost`、`127.0.0.1`、`[::1]` 等回环地址允许 HTTP。不要把 `/chat/completions` 填进根地址。

同一根地址下，密钥留空会保留已有密钥。换远程地址需要重新填写密钥；换到本地地址不会沿用旧服务的密钥。密钥通过 Zotero 宿主的登录信息存储保存，不显示在普通设置中，也不进入导出。

每段请求最多约 2000 字符，并发最多 2 个，超时 25 秒。鉴权失败停止队列；限流和服务故障最多重试一次。原文、模型、地址、目标语言和提示词版本参与缓存隔离。译文缓存上限约 50 MB，清理缓存不删除学习记录。

## 生词本与复习

生词本提供搜索、学习状态筛选、释义与例句编辑、批量删除和论文来源跳转。同词去重，多篇论文中的例句分别保存。

来源记录使用文库 ID、附件 key、父条目 key、标题、页码及可用的位置矩形，不依赖易变的文件路径。附件丢失或未下载会显示提示，例句不会因此删除。页码跳转需要来源附件仍存在于对应文库中。

闪卡正面显示词汇和来源例句，背面显示释义、音标、例句译文及发音入口。选择「忘记、困难、记得、轻松」评分。使用锁定的 ts-fsrs 5.4.2，目标保持率 0.9，先处理到期卡，每日最多引入 20 个新词。日期和每日额度按本机时区计算，时间以 UTC 保存。标记掌握暂停复习；恢复学习保留原进度。

## 备份、恢复与 Anki

在「备份与迁移」操作：

- **JSON**：完整保存词汇、例句、论文位置、卡片、日志及非敏感阅读偏好。格式标识是 `culingo-zotero`，版本为 1。不含密钥、翻译缓存和 PDF。
- **CSV**：词汇交换，最小模板为 `word,meaning`。插件导出还包含 `phonetic,example,translation,source`，同词多个例句分别占行。新词创建新卡，已有复习进度不会被 CSV 覆盖。CSV 不用于完整保留掌握状态和复习进度。
- **Anki TSV**：五列依次为单词、释义、例句、译文、论文来源。在 Anki 创建对应五字段笔记类型，导入时选制表符分隔，并允许字段内 HTML；换行以 `<br>` 保留。

导入先预检有效、重复、无效词汇数量，再点击「确认合并导入」。JSON 采用合并：词汇保留较新编辑、例句去重、卡片保留最近复习状态、日志按 ID 去重。损坏或未来版本文件不会覆盖现有数据。

浏览器 JSON 不能在这里导入。需要在两端复制词汇时使用 CSV，并在各端分别备份。恢复 JSON 不会恢复 PDF 或 API 配置；在新配置中要另外恢复 Zotero 文库并填写翻译配置。

## 数据位置与卸载

Zotero **用户配置目录**下的 `culingo-zotero` 文件夹：

| 文件 | 用途 |
| --- | --- |
| `learning.sqlite` | 词汇、例句、卡片、复习日志、非敏感设置 |
| `cache.sqlite` | 离线词典、初始化进度、可清理译文缓存 |

不向 Zotero 主数据库添加自定义表，不提供本机 HTTP 数据服务。安装、升级、禁用和卸载不自动删除学习数据。「清空翻译缓存」只删除译文；「清除学习记录」需在界面中单独确认。建议定期导出 JSON，关闭 Zotero 后也可额外备份插件数据目录。宿主登录信息存储不被描述为独立加密保险箱。

## 构建与验证

在本目录运行，所有 JavaScript 依赖均安装在本目录的 `node_modules`，使用独立锁文件：

```powershell
npm ci
npm run typecheck
npm test
npm run build
npm run package:source
```

构建生成 `dist/culingo-zotero-0.1.0.xpi`；源码归档为 `dist/culingo-zotero-0.1.0-source.zip`，不包含依赖目录、测试配置或缓存。插件通过文件安装更新；自动更新已关闭。Manifest 中的保留域名更新地址用于满足 Zotero 10 的格式要求，不提供在线更新服务。

真实宿主测试使用项目本地独立配置和生成的 PDF，不操作日常文库：

```powershell
$env:ZOTERO_EXE = 'E:\Zotero\zotero.exe'
npm run test:host
```

该测试依次检查原生阅读流程、重启和全新配置 JSON 恢复，并启动临时回环模拟 API。`.cache/host-test/latest-results.json` 保存最近通过的结果；测试配置、模拟密钥和测试日志不进入安装包。

独立词典转换流程、第三方来源见 [THIRD_PARTY.md](THIRD_PARTY.md)。实际验证记录及待试用项目见 [docs/VERIFICATION.md](docs/VERIFICATION.md)。

## 支持边界

首版支持具有可提取文字的 PDF 原版式阅读。扫描件 OCR、EPUB、网页快照、重排阅读、原生批注自动创建、云同步和译文 PDF 导出不在范围内。公式和表格不重建排版；复杂双栏或阅读顺序不可靠时，可编辑例句并使用选区或手动段落翻译。

自动坐标接口仅针对 Zotero 10.0.5 适配。接口不兼容时暂停自动高亮，保留选区查询的学习中心入口。其他 Zotero 版本、真实供应商、不同论文排版与连续一周日常使用仍需补充验证。

公式行过滤只跳过含有明显等式或数学符号的整行，普通解释性正文仍按词频提示。复杂排版、OCR 误识别或夹在正文中的公式可能需要手动标记掌握；关闭自动高亮后仍可使用划选查词。
